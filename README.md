## 🎯 Resumen del Proyecto

Caso de estudio enfocado en el desarrollo front-end, maquetación avanzada y optimización del sitio web corporativo para la marca **KLIK**. Este proyecto transformó una estructura base de CMS en una experiencia visual inmersiva de alta gama con identidad en modo oscuro, integrando código a medida para romper las limitaciones visuales tradicionales.

🔗 **Sitio web en producción:** [https://klikve.org/](https://klikve.org/) *(Desarrollado como proyecto profesional para KLIK)*

---

## 🛠️ Stack Tecnológico y Arquitectura

| Categoría | Tecnología / Herramienta | Propósito en el Proyecto |
| :--- | :--- | :--- |
| **CMS** | WordPress & NGINX | Núcleo de gestión y entorno de servidor optimizado. |
| **Builder** | Elementor Pro | Estructuración base de páginas y maquetación visual. |
| **Estilos** | CSS3 Avanzado | Creación de componentes fluidos, variables y efectos visuales. |

| **Seguridad** | WAF & Wordfence | Blindaje contra accesos no autorizados y optimización web. |

## 💎 Aportes Técnicos Destacados (Custom Code)

> Para lograr acabados profesionales fuera de los estándares de las plantillas comerciales, se programaron e inyectaron los siguientes componentes a medida:

*   🌐 **Contenedores Full-Width (`100vw`):** Estructuras fluidas mediante `calc()` y posicionamiento relativo para evitar los márgenes rígidos del maquetador y lograr un diseño de lado a lado.
*   🌌 **Banner Hero con Efecto Aurora:** Fondo reactivo con gradientes radiales y animaciones mediante bucles de opacidad y transformaciones continuas (`@keyframes`).
*   🧊 **Grid de Servicios Interactivo (3x2):** Tarjetas con perspectiva 3D real (`perspective`, `rotateX`) y revelado de información en estado *hover* con curvas *cubic-bezier*.
*   💬 **Micro-interacciones en Botones CTA:** Botones de WhatsApp optimizados con expansión fluida de ancho y desplazamiento dinámico de iconos al pasar el cursor.
